### 1️⃣ Unsupervised Anomaly Detection in Financial Transactions

A full-stack web application that detects unusual and potentially fraudulent financial transactions without labeled data, using the Isolation Forest unsupervised algorithm to flag suspicious patterns and showing the results in an interactive dashboard.

- **Tech Stack:** React.js, Node.js, Express.js, PostgreSQL, Material UI, Isolation Forest
- 🔗 [GitHub Repo](https://github.com/neelamlikitha/Unsupervised-Learning-For-Anamoly-Detection-In-Financial-Transactions) &nbsp;|&nbsp; 🌐 [Live Demo](https://financial-anomaly-frontend.onrender.com/login) <sub>(may take a minute to load)</sub>

<br/>

### 2️⃣ Digital Solutions For Good Governance And Justice

A digital platform designed to promote transparency, accountability and easy access to justice, helping citizens interact with governance services and report or track issues through a simple, user-friendly web interface.

- **Tech Stack:** HTML5, CSS3, JavaScript, Flask (Python), MongoDB
- 🔗 [GitHub Repo](https://github.com/neelamlikitha/Digital-Solutions-For-Good-Governance-And-justice) &nbsp;|&nbsp; 🌐 [Live Demo](https://digital-solutions-for-good-governance.onrender.com/) <sub>(may take a minute to load)</sub>

<br/>

### 3️⃣ Latent Space Representation using Autoencoders & Variational Autoencoders

A deep learning project that explores how Autoencoders and Variational Autoencoders (VAEs) learn compact latent space representations of data, comparing how each model encodes, reconstructs and generates data.

- **Tech Stack:** Python, PyTorch, MNIST, PCA, t-SNE
- 🔗 [GitHub Repo](https://github.com/neelamlikitha/Latent-Space-Representation-for-AE-and-VAEn) &nbsp;|&nbsp; 📓 [Colab Notebook](https://colab.research.google.com/github/neelamlikitha/Latent-Space-Representation-for-AE-and-VAEn/blob/main/MINI_PROJECT_corrected.ipynb#scrollTo=cell-02)
